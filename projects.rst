Interactive Visualizations
--------------

- `Entangled Graphs <https://nomicflux.github.io/entangled-graphs>`_ - Design quantum circuits and explore basic algorithms
- `Algorithm Visualizations <https://nomicflux.github.io/okasaki-visualization>`_ - Data structures from Okasaki's Purely Functional Data Structures, as well as other functional structures.
- `P-adic Number Visualization <https://nomicflux.github.io/PadicVisualization/>`_ - A geometric representation of p-adic numbers based off of Sierpinski's polygons, and how they change under various transformations.
- `Cohomology <https://nomicflux.github.io/cocycle/>`_ - Čech cohomology playground to show how nerve complexes and cocycles work.

Projects
----------------

- `Dialect Coach <https://github.com/nomicflux/dialect-coach>`_ - Chat with AI agents to practice various languages by focusing on local dialects.
- `Sarf <https://github.com/nomicflux/sarf>`_ - Browser extension to show morphological information for Arabic words.
- `Skeptic <https://github.com/nomicflux/skeptic>`_ - Clojure static type-checker plugin for plumatic/schema.
- `Danger Mouse <https://github.com/nomicflux/danger-mouse>`_ - A Clojure library for clean handling of errors. Specialized for use in Transducer pipelines.
- `SCRPG Helper <https://github.com/nomicflux/scrpg-helper>`_  - Helper application for the Sentinal Comics TTRPG, featuring dice statistics, combat tracking, and character creation.
- `Servant and Opaleye Tutorial <https://github.com/nomicflux/servant-opaleye-blog>`_ - Setting up a blog with the Haskell web framework Servant and the database library Opaleye.
- `Threals <https://github.com/nomicflux/threals>`_ - Threals, a three-player variant on `Surreal Numbers <https://en.wikipedia.org/wiki/Surreal_number>`_ and `Combinatorial Game Theory <https://en.wikipedia.org/wiki/Combinatorial_game_theory>`_.  I've been working on their theory, though the main holdup is that I cannot seem to find a zero game, so the theory cannot be made into a group.
- `Guitar Chord Trainer <https://github.com/nomicflux/GuitarChordTrainer>`_ - Guitar chord finder, with working version `here <https://nomicflux.github.io/GuitarChordTrainer>`_.
- `Hexation <https://github.com/nomicflux/hexation>`_ - Three-player game based on `Domineering <https://en.wikipedia.org/wiki/Domineering>`_, with AIs as players. They've been trapped in a cage since birth, learning the game through playing each other - watch how these recluses think and picture the board.
